SmartFlow

Field Installed (1 Site)
2026
Automated controller for a residential deep-well water pump
Solo developer Leon, Iloilo · Residential Deep-Well Automation

Deep-well water pumps easily burn out if they run dry or run too long unattended. To solve this for my home in Iloilo, I built a two-node automation system: an ESP32 master connected to a 1.5 HP motor contactor, and an ESP8266 at the 660L water tank with an ultrasonic sensor. They communicate over a 40-meter CAT6 wire using RS-485 to avoid motor electrical interference. Even if the home Wi-Fi disconnects, local firmware logic ensures the pump shuts off automatically before running dry.

  • • 40-meter wired RS-485 link with CRC checks to eliminate electrical noise from the motor.
  • • Local firmware safety timers that shut down the motor within 15 seconds if dry-run conditions are detected.
  • • Native Android app built with Kotlin and Jetpack Compose for Bluetooth setup and tank level monitoring.

HavenStay BHMS

Course Project
2026
Bed-level rental management and utility billing for student boarding houses
Solo developer Information Management Coursework · Student Housing

Built as solo coursework for Information Management, HavenStay is modeled around student boarding houses near universities. Most rental software assumes whole apartments, but boarding houses rent by individual bed spaces and share water and electric meters. I designed HavenStay to track bed-level vacancies and assignments, split shared utilities fairly among occupants, and enforce audit records using 45 MySQL triggers so transaction histories cannot be altered or lost.

  • • Bed-level inventory tracking for individual bed vacancies, deposits, and lease terms.
  • • Automated utility calculation that splits shared water and electric sub-meters fairly among tenants.

How I build

Habits I actually use, tied to work in the repos.

I notice a problem, read enough to try something, break it into parts, build a small version, test it, and go back to the docs when I get stuck.

Put important rules in the database

App code can skip a path. In HavenStay, 45 MySQL triggers write before-and-after snapshots when balances or room assignments change. CONVERA keeps session checkpoints in SQLite.

If it can burn a motor, the shutdown stays on the device

SmartFlow decides dry-run timeouts, run limits, and a lost tank-node link in C++ on the ESP32, switching a CJX2 contactor. If Wi-Fi or Firebase is down, the pump still stops.

Tests and a real run, not just a demo

CONVERA has 338 offline backend tests. Faith Laundry has 289 automated tests (199 JUnit, 90 Vitest). HavenStay has Pest checks on architecture boundaries. SmartFlow ran for days at home with multimeter checks before I left it unattended.

I use AI, then I check the work

I use it for drafts, test ideas, and explanations. I do not paste from it into a repo until I have read the docs, compiled, and tried the path myself.

I still overbuild when I am interested. Hardware and course deadlines have been the main things that force me to ship the part that is actually needed.
