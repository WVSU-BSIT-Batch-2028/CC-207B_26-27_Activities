## Overview

This responsive portfolio introduces me, presents my education, skills, and services, and showcases selected academic and community projects. It is built with plain HTML, CSS, and JavaScript, without a framework or build step.

## Pages

- **`index.html`:** Home, About, Education, Technologies and Services, Projects, and Contact. Education and skills share a two-column section. The project list uses selectable tabs; clicking a preview image opens it in a same-page viewer.
- **`project.html`:** A project case study showing its summary, role, timeline, status, technology stack, contributions, and screenshots. Screenshot images open in a viewer with previous/next controls. The page also links back to all projects and to the next project.

## Project Data

- `js/projects-list.js` contains the six project records and their screenshot details.
- `js/script.js` builds the project previews and case-study pages, and handles the tabs and screenshot viewers.

Project screenshots are stored in folders under `assets/`. Profile and campus photos are in `assets/images/`, and interface icons are in `assets/icons/`.
