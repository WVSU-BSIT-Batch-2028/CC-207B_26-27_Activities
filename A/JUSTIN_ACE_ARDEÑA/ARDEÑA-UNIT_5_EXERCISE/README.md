# ardena_unit5_exercise

Two-screen Flutter app (Profile + My Pet) for CC 207B Unit 5.

## Setup
1. Run `flutter create .` inside this folder once (generates android/ios/web/etc. folders).
2. `flutter pub get`
3. `flutter run`

## Make it yours
- Edit the constants at the top of `lib/main.dart` (name, tagline, info rows, biography, pet name).
- Replace the placeholder files:
  - `assets/images/profile.png` -> your photo
  - `assets/images/pet.png` -> your pet's photo
  - `assets/sounds/pet_sound.wav` -> your pet's sound (if you use .mp3, also update `kPetSoundAsset`)
