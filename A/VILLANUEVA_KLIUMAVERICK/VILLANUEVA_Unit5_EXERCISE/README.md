# Villanueva Unit 5 Exercise

A Flutter profile and pet demo with bottom navigation, accessible image
labels, and an `audioplayers` sound button.

## Run the app

```sh
flutter pub get
flutter run
```

## Media

- `assets/images/Kliu Villanueva.jpg` is the profile photo.
- `assets/images/Squonk.jpeg` is Squonk's photo.
- `assets/sounds/pet_sound.wav` is an original synthesized Squonk call: a
  bubbly, low croak that rises into a brief squeak.

The WAV can be replaced while keeping its asset path declared in `pubspec.yaml`.
