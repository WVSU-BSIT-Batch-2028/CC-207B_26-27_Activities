## Application Features

1. **Profile Screen** – Displays personal information, biography, hobbies, and class schedule.
2. **My Pet Screen** – Displays pet information, plays sound, counts interactions, and supports double-tap heart animation.
3. **Gallery Screen** – Displays six photos in a responsive grid.
4. **Photo Details Screen** – Opens a selected photo and allows the user to mark it as a favorite.
5. **Favorite Photo** – Displays a star on the selected favorite photo.
6. **Hobbies** – Displays hobbies using Chip and Wrap widgets.
7. **Class Schedule** – Displays class schedules using the Table widget.
8. **Reset Confirmation** – Uses AlertDialog to confirm before resetting the pet's sound counter.
9. **Persistent Navigation** – Uses IndexedStack to preserve screen states when switching tabs.
