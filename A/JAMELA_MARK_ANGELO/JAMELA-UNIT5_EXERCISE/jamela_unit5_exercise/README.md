# jamela_unit5_exercise

CC 207B Unit 5 Exercise - Profile + My Pet app (Flutter)
Mark Angelo A. Jamela, BSIT 3-A

## Run
    flutter pub get
    flutter run          # or: flutter run -d chrome / -d windows

## Replace before submitting
- `assets/images/profile.png` - your photo
- `assets/images/pet.png` - your pet's photo
- `assets/sounds/pet_sound.mp3` - your pet's sound (if you use .wav, update `petSoundAsset` in `lib/screens/pet_screen.dart`)
- Placeholder details in `lib/screens/profile_screen.dart` and `lib/screens/pet_screen.dart`
