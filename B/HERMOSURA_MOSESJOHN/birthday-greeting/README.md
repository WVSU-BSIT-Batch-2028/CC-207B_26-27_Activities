# Birthday Greeting

## Description

A simple, personal birthday greeting page designed as a digital card. The page uses a warm, romantic visual style and a mobile-first layout that also works on larger screens. Opening the envelope reveals a handwritten-style message with a typewriter effect and falling petals.

## Purpose

This project was created to celebrate the author's girlfriend with a thoughtful and creative birthday message, and also to test his skills.

## Features

- Interactive envelope
  - Click to open and close the envelope
  - Reveals the letter with an opening animation
- Animated birthday letter
  - Displays the message with a typewriter effect
- Falling petals
  - Adds animated petals while the envelope is open

## Tech Used

- HTML
- CSS
- JavaScript
- Google Fonts
