# Me & Lurk — Unit 6 exercise

Open this folder in VS Code. Run `flutter pub get`, then `flutter run -d chrome` (or select an Android device).

This is a separate copy of the Unit 5 project. The original is preserved.

## Activity requirements
- IndexedStack preserves all three tabs and the bark count during tab switches.
- Photo model, six local photos, GridView.extent (160, spacing 8, padding 8), captions as semantic labels.
- PhotoScreen passes a bool result back; the gallery stores one favorite and displays its star.
- Five supplied hobbies displayed with Chip and Wrap.
- ClassSlot table uses supplied Monday classes and Tuesday CC 210 (7–9 AM assumed).
- Reset count opens a confirmation dialog; Cancel/back preserves the count; Reset clears it. Disabled at zero.
- Professor's AudioPlayer / onPlayerComplete / AssetSource / dispose pattern retained. Stream subscription is also canceled during disposal.

## Assets
Your existing profile and Lurk photos and MP3 are copied from Unit 5. Gallery includes those two photos plus four free Unsplash landscape samples. Each is under 500 KB. See assets/images/gallery/SOURCES.md for sources.
