# Juan Carlos Moje — Portfolio

Open index.html in a browser. Keep index.html, style.css, and script.js together. No installation, images, external fonts, or libraries are needed.

The page includes an introduction, skills in development, a Unit 4 project, an anime quote, and a school email link. The Show details button demonstrates JavaScript.

Review the introduction and skills before submitting, and edit them if they do not reflect your experience.

## Submit

Copy this folder into B/JUAN_CARLOS_MOJE/ inside your cloned class repository. Rename the portfolio folder to MOJE-UNIT_4, unless your instructor requires a different activity name. Commit and push your files, create one pull request to the original repository, and notify your instructor.
